# delicias_carol

## Publicación y SEO

Antes de publicar, busca `TU-DOMINIO.com` en el proyecto y sustitúyelo por el dominio público HTTPS definitivo. Aparece en canonical, datos estructurados, Open Graph, tarjeta de X, `robots.txt` y `sitemap.xml`.

La imagen de vista previa para WhatsApp, Facebook y otras redes está en `assets/delicias-carol-social.jpg` (1196 × 630 px).
